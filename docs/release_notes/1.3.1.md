Beta 1.3.1: Online-Spiel (Schritt 1)

- Über das Internet spielen: Der Gastgeber öffnet in der Lobby „Online (Internet)“ und bekommt einen Raumcode (z. B. KATZE-42), einen Link und einen QR-Code. Mitspieler geben den Code in der App unter „Beitreten“ ein oder öffnen den Link im Browser. WLAN- und Online-Gäste können gleichzeitig mitspielen.
- Dafür braucht ihr einen eigenen kostenlosen Vermittler bei Cloudflare (Knopf „Deploy to Cloudflare“ im README). Seine Adresse tragt ihr unter Einstellungen → Online ein und prüft sie mit „Verbindung testen“.
- Das Spiel läuft weiter auf dem Handy des Gastgebers. Der Vermittler reicht nur Nachrichten durch und speichert keine Inhalte.
- Neuer App-Link `maumauflip://join?r=CODE&v=VERMITTLER`.
